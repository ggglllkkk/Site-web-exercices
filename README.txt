Pour remettre à 0 la base de données :
    Exécuter (double-clic) "reset_database.bat"

Pour lancer le site:
    Exécuter (double-clic) "app.bat"

Pour se connecter au site:
    Rentrer dans la barre d'URL (!! pas la barre de recherche !!) l'adresse affichée sur la console de l'application (!! pas celle commençant par 127, l'autre !!)

Pour voir la base de données:
    (!! Recommandé de le faire quand plus personne n'interagit avec le site !!)
    Ouvrir "database.csv". Si une boite de dialogue s'affiche, sélectionner comme séparateur , ou "comma".
